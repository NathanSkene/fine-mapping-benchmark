# Frozen development evidence

These compact artifacts accompany the [validation record](../validation.md).
They contain synthetic development results and native integration fixtures,
not withheld competition truth or a universal method leaderboard.

`local-development-final` and `imperial-development-final` record the same
implementation commit with different variant/replicate counts and available
predictors. Source SHA-256 manifests and sessions preserve their comparison
context. Runtime includes the observed environment and is not a controlled
hardware comparison. Bootstrap contrasts require their mechanism, paired
eligibility and small-cluster interpretation.

The native directories preserve integration outputs for official FINEMAP and
SBayesRC. Convergence of the SBayesRC short chain has not been established;
neither native smoke is a genome-wide performance benchmark.

The [11 October integration repair ledger](integration-repairs-20261011/README.md)
preserves the immutable `eb2d9bc34190` integration census: 1,158 successful
locus attempts, 240 declared absences and six unexpected validation failures.
It separates exact generation repair, native FINEMAP precision inspection,
SparsePro output-transport/parser checks, the exact-source dimension audit and
the final repaired-source package check (1,824 passing expectations, 24 explicit
skips; separate source-native checks passed 218 expectations). Fresh campaign
plans and execution gates remain separate. Failed v1/v3 replay harnesses and
the preceding package snapshots are preserved.
Each record has a logical artifact label and SHA-256; retained raw archives
are not represented as publicly downloadable evidence. The older native
execution quality check used only 20 retained draws per chain.

`campaign-hardening-20261010` preserves the later complete R package-check
record, exact archive-file hashes and explicit optional-test gaps. The linked
native parser and retention proofs verify executed interfaces. Full campaign
results require their own frozen plan, completion census and analysis manifest.

The [regional paper census and stage-analysis record](paper-stage-census-20261011/README.md)
binds 285 publication/math checks and an export of a prior sealed development
collection. It distinguishes implementation/acceptance changes from a changed
generating experiment and records why the historical two-genotype-cluster
percentile envelopes are descriptive rather than validated confidence bounds.
It does not alter inference or establish full-campaign rankings.

Full per-task predictions, public-input/assessor releases, raw logs and RDS
objects are retained in the local checkout's ignored `results/` directories.
Run the documented scripts with a fresh output directory to generate an
equivalent development release. The final competition protocol additionally
requires independent custody and unreleased targets.
